NEXORA Rclone Backup

NEXORA Rclone Backup is a personal-use utility for transferring and maintaining private research-data backups between an operator-managed computer or cloud server and the operator's own Google Drive account using rclone.

This website is informational only. It does not provide a public login, trading service, or access to backup files.

How Google Drive access is used

The operator explicitly authorizes Google Drive access through Google's OAuth consent process. That access is used for permitted backup tasks such as uploading, listing, verifying, downloading and restoring files. The exact permissions depend on the scopes granted during authorization.

Data and security

Backup contents and OAuth credentials are not published on this website. The backup process operates on operator-controlled systems and uses Google Drive as the storage destination. See our Privacy Policy for details.

Terms of use

This is a personal, non-commercial tool, not a service offered to the public. There are no public accounts, subscriptions, guarantees of continuous availability, or financial/trading services. Access to the underlying backup system is restricted to the operator.
