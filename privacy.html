Privacy Policy

Effective date: 25 November 2026

This policy describes how the privately operated NEXORA Rclone Backup utility uses Google account access and backup data. It is intended solely for use by the operator of the utility; it is not a publicly available product or trading service.

Google user data accessed

With the operator's explicit OAuth authorization, the utility may access Google Drive file and folder metadata and file contents within the permissions granted. Access is used to create, list, upload, verify, retrieve, and restore the operator's backup files. The specific OAuth scope is displayed by Google during authorization.

Purpose and use

Google Drive data is used only to maintain and verify the operator's private backups and perform requested restoration operations. This includes recording operational status, timestamps, object identifiers and integrity checksums. No Google user data is sold or used for advertising by the operator.

Storage and sharing

Backup files reside in the operator's Google Drive account and, where necessary, on operator-managed local or cloud systems. The operator does not deliberately disclose these files or OAuth tokens publicly. Google Drive and the underlying infrastructure providers process data as required to supply their services and subject to their own policies.

Tokens and safeguards

OAuth authorization tokens are intended to be kept in restricted configuration storage on the operator-managed backup system, not in this public website or repository. Access and retention depend on the operator's system configurations, Google account permissions and backup policies. No technical or cloud service can promise absolute security.

Retention and deletion

The operator controls backup retention and may delete backup files in Google Drive or local storage according to applicable preservation requirements. OAuth access can be revoked in the Google Account's third-party connections/security settings. Revoking access stops new authorized Google Drive operations but does not automatically remove existing backup files.

Website data

This static website contains no login, contact form, advertising code or custom analytics. It is hosted by GitHub Pages; GitHub may process normal website request information under its own privacy policy.

Policy updates and contact

This policy may be updated if the utility's data use or permissions change. Questions may be directed to the maintainer through the GitHub profile.
